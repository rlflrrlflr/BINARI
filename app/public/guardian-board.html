수호신 디자인 버전 보드

오행(형태) × 모드 A/B/C(상태) × 버전(계보). 아래 그리드는 현재 코드로 실제 렌더링되며, 셰이더와 2D 형태 함수는 app/src/App.jsx·구버전 파일에서 그대로 추출해 쓴다.

B 열은 화면 중앙을 계속 누르고 있는 상태를, C 열은 판결 반응(GO → HOLD → STOP → 해체)을 반복 재생한다. 실제 앱에서는 손끝 위치와 판결 방향에 따라 달라진다.

1. 현재 버전(v97) — 오행 5 × 모드 3

이 브라우저에서 WebGL을 못 씁니다 — 아래 2D 계보 섹션은 그대로 보입니다.

아래는 오행별 지금 형태와 그 형태가 거쳐온 변천(점선 아래).

2. 같은 오행, 버전별로 — GL 셰이더 계보 12종

git 히스토리에 남아있는 서로 다른 셰이더 12개를 전부 컴파일해 같은 조건으로 나란히 돌린다. 오행과 모드를 바꿔가며 어느 버전이 나았는지 직접 비교하면 된다. (v60 이전 GL과 v68~v92의 sim 엔진 B 모션[물레·홀림]은 이 저장소 히스토리에 코드가 없어 렌더 불가 — 3·4절의 이력으로만 남는다.)

3. 형태의 계보 — 2D 세대별(오행 5)

WebGL 이전의 Canvas2D 형태 함수를 구버전 파일에서 뽑아 나란히 돌린다. 같은 코드인 버전은 한 세대로 묶었다(코드가 안 바뀐 구간은 형태도 안 바뀌었다는 뜻).
