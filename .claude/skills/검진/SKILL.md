# 검진 — 사용자는 이 한 단어만 말한다

이 리포의 소유자는 개발자가 아니다. **명령어를 외우게 하지 마라.**
"검진"이라는 말이 나오면 아래를 대신 실행하고, 결과를 한국어로 보고한다.

## 실행

```
cd app && node health-check.mjs
```

빌드·미리보기 서버는 스크립트가 알아서 준비하고 끝나면 정리한다. 사용자에게
"터미널을 하나 더 열어라", "먼저 빌드해라" 같은 요구를 하지 마라 — 그건 이 도구의 실패다.

## 보고 방식

- 출력의 `무엇이:` / `어떻게:` 를 그대로 옮기지 말고, **사용자가 결정할 수 있는 형태**로 줄여 말한다:
  ① 지금 배포해도 되는가 ② 고쳐야 할 게 있으면 그게 무엇이고 내가 고칠 수 있는가.
- ✗(심각)가 하나라도 있으면 **배포하지 않는다.** 고치겠다고 제안하고, 승인받으면 고친 뒤 다시 검진한다.
- △(주의)는 "급하지 않다"는 것까지 함께 말한다. 겁주지 않는다.
- 검사를 건너뛴 게 있으면 숨기지 말고 무엇을 못 봤는지 밝힌다.

## 이어서 할 것

- 코드를 고쳤다면 검진만으로 끝내지 말고 `node e2e/smoke.mjs` (26 시나리오)까지 돌린다.
- 새 사고를 고쳤다면 `app/health-check.mjs`에 **그 사고를 잡는 검사를 하나 추가**한다.
  이 목록이 길어지는 게 정상이다.
- 판단 배경과 남은 위험은 `app/유지보수_규칙.md`.

## 하지 말 것

- 검진 결과를 근거로 `main`에 밀지 마라. main 푸시 = 자동배포이며, **사용자의 명시 지시가 있을 때만** 한다.
