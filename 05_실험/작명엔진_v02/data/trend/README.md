# 연도별 추세 데이터 — 사람이 한 번 채우는 자리

## 왜 이 폴더가 있나

이름별 **누적 인원·성비·순위**는 `lib/usage.mjs`가 대법원 미러에서 자동으로 가져온다.
그런데 **연도별 추세**만은 자동화가 안 된다. 이유는 둘이다.

1. **미러가 이미 합산돼 있다.** `randkid/name`은 "2008~2019년 수치 합산"이라 연도 축이 데이터에 없다. 차분해도 복원 불가.
2. **원천이 차단돼 있다.** `stfamily.scourt.go.kr` · `efamily.scourt.go.kr` · `www.scourt.go.kr` 전부 에이전트 환경에서 접근 불가(응답 000).

그래서 이 구멍은 **사람이 한 번 메우면 그 뒤로는 엔진이 계산**한다.

## 왜 추세가 필요한가

누적값만 보면 **신흥 이름이 구조적으로 과소평가**된다. 실측 예:

| 이름 | 대법원 누적(2008–2019) | 통계 사이트(~2025) | 차이 |
|---|---|---|---|
| 태오 | 1,911 | 5,895 | **3배** — 최근 급상승 |
| 태윤 | 8,712 | 11,539 | 완만 |
| 리오 | 360 | 547 | 상승 |

"지금 뜨는 이름"과 "예전에 많이 쓰던 이름"을 구분하려면 연도 축이 있어야 한다.

## 채우는 법

**대법원 전자가족관계등록시스템 → 통계 → 출생신고 시 선호하는 이름**
`https://stfamily.scourt.go.kr/st/StFrrStatcsView.do?pgmId=090000000025`
(기간·지역·성별로 조건 검색 가능. 이름 통계는 **매일 갱신**된다)

연도별로 조회해서 받은 걸 **형식 안 맞춰도 그대로** 넣으면 된다.

```bash
node data/trend/import.mjs 2024 받은파일.csv          # 엑셀 → CSV 저장한 것
node data/trend/import.mjs 2024 받은파일.txt --gender=m # 성별 열이 없을 때
cat 붙여넣기.txt | node data/trend/import.mjs 2024 -    # 화면에서 긁어 붙여넣기
```

**받아들이는 것** — 쉼표/탭/공백 아무 구분자 · 헤더 있든 없든 · 열 순서 아무거나 ·
성별이 `남/여`·`남자/여자`·`M/F` 아무거나 · `2,431` 처럼 천단위 쉼표 있어도 됨 · 순위 열 섞여 있어도 무시.
같은 연도에 여러 번 넣으면 **병합**된다(남아 파일·여아 파일을 따로 넣어도 됨).

결과는 `data/trend/<연도>.csv` 로 정규화된다:

```csv
name,gender,count
민준,m,3120
서윤,f,2980
```

- 한 해에 한 파일. 파일이 하나도 없으면 엔진은 추세를 `null`로 두고 **모른다고 표기**한다(추측하지 않는다).
- **최소 3개 연도**가 있어야 "최근 3년 추세"가 나온다.
