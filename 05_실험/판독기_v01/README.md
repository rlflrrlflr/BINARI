# 판독기 v01 — 여러 하늘을 한 파일로

**같은 생년월일시를 서로 다른 문명의 방식으로 읽는다.** 맥락은 `전략로그.md` 2026-08-11 결론 2.

## 왜 만드나

경쟁 8개사는 전부 **사주 하나**만 본다. 우리는 같은 순간에 **판독기를 여럿 걸고 답이 겹치는지 갈리는지**를 보여준다.
이건 새 방법론이 아니라 **이미 이 리포의 원칙**이다 — 발음오행 2체계 병기 · 억부/조후 일치 여부 표시 · 확신도 3단.

> **겹치면 그 자리는 확실히 박힌 것이고, 갈리면 갈린다고 말한다. 감추지 않는 것이 상품이다.**

실사용에서 확인된 것: 갈림이 오히려 정보였다. 형 리한은 여덟 글자가 *"표현하는 자리 0"*이라 하는데
서양의 태양·달이 둘 다 공기(말하고 옮기는 기운)다. 모순이 아니라 **"안에는 공기가 가득한데 나올 문이 안 났다"** —
갈리는 그 자리가 그 사람의 급소였다.

## 실행

```
node 05_실험/판독기_v01/verify.mjs                       # 자체 검증 27건
node 05_실험/판독기_v01/read.mjs 1990 3 15 14 30 M        # 한 사람을 전부 걸어 본다
```
의존성 없음. Node 18+. **개인정보는 인자로만 받는다 — 파일에 박지 않는다.**

## 검증에서 잡은 것 — 기준점이 틀렸다

자바 웨톤의 기준점을 처음에 **자바력 원년(1 Sura 1555 AJ = 1633-07-08 율리우스)을 '금요일 레기'**로 잡았다.
**그런데 그날은 금요일이 아니라 월요일이었다** — 그레고리 환산과 율리우스력 직접 계산이 같은 답을 냈다.
→ 기준점을 **1945-08-17 인도네시아 독립일 = 금요일 레기**로 교체했다. 이 날이 금요일인 것은 자체 검증된다.

**절대 명칭(레기냐 파힝이냐)은 아직 외부 확인이 필요하고, 주기성(5일·35일)만 여기서 검증된다.**
이걸 `derived`로 표시해 둔 이유다 — 검증 못 한 것을 검증했다고 쓰지 않는다.

## v02 — 좌표가 필요한 판독기 (`lib/sky.mjs`)

위도·경도가 있어야 계산되는 것들. **핵심은 다른 문명의 시간 축이다.**

| 판독기 | 문명 | 무엇을 답하나 | 사주의 무엇에 대응하나 |
|---|---|---|---|
| 상승궁(ASC)·중천(MC) | 헬레니즘 | 태어난 순간 동쪽에 떠오르던 자리 | 일간·월지에 준하는 세 번째 기둥 |
| 홀사인 12하우스 | 헬레니즘 | 삶의 열두 자리 | 십성의 배치 |
| **연간 프로펙션** | 헬레니즘 | **올해의 주제** | **세운** |
| 파트 오브 포춘 | 아라비아 | 재물과 몸의 자리 | 재성 |
| **비민쇼타리 다샤** | 인도 | **지금 어느 시기인가**(120년) | **대운** |
| **아쉬타쿠타 36점** | 인도 | **두 사람이 맞는가** | 궁합 |

### 상승궁은 외부 대조표 없이 검증된다
알려진 답안지가 없어도 **물리로 검사할 수 있다** — 해가 뜨는 순간에는 해가 동쪽 지평선에 있으므로
**그때 상승궁은 태양 황경과 거의 같아야 한다.** 남중 무렵에는 **중천이 태양과 겹쳐야** 한다.
춘분·하지·추분·동지 네 날로 검사해 둘 다 오차 8도 이내로 통과한다(`verify-sky.mjs`).
그리고 상승궁은 **하루에 열두 자리를 모두 지나야** 한다 — 이것도 검사한다.

### 실사용에서 나온 교차 검증
두 아이에게 걸었더니 **인도 궁합법이 사주와 독립적으로 같은 답을 냈다.**

- 사주 대조: *"두 아이는 거의 모든 것이 반대인데 비어 있는 자리 하나만 같다."*
- 아쉬타쿠타 36점: **16/36.** 여덟 항목 중 일곱이 0~1.5점인데 **나디(체질)만 8점 만점.**
  그런데 나디는 인도 궁합에서 **유일하게 '달라야 만점'인 항목**이다.
  → **"둘은 안 맞는다. 유일하게 맞는 한 가지가 서로 다르다는 것이다."**

시간 축도 겹쳤다. 형은 사주로 **18~37세가 규칙에 매인 스무 해**인데,
인도 다샤로도 **라후 시기가 12.1~30.1세**다 — 두 문명이 독립적으로 같은 구간을 무겁게 본다.
