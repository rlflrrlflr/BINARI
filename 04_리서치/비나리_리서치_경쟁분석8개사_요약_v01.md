### 시장 문법 4개

| 문법 | 내용 |
|---|---|
| 엔진은 다 같다 | 8개 모두 만세력 + 생성형 AI. **차이는 기술이 아니라 그걸 숨기냐(청월당=역술가 서사) 드러내냐(사주아이·아스텔로)의 선택** |

| 메타 → 스레드 → 랜딩 단일 공식 | 리스티클로 훅, 랜딩에서 무료 미리보기 → 결제 게이트. 신흥일수록 이 퍼널 하나에 예산 집중 |
| 대면에서 못 꺼내는 고민이 고마진 | 재회·속궁합·임신·바람기·집착. **8개 중 5개 보유** |

## 이 덱이 비나리 판단에 낸 구멍

| 비나리가 이미 내린 판단 | 덱과 충돌하는 지점 |
|---|---|
| **결정 3 — 4,900원 단일가** | **운세위키 고민풀이가 정확히 4,900원.** "빈 자리"가 아니라 정면 충돌 |
| **결정 3 — 리포트 3,000~5,000자** | 운세위키는 같은 가격에 "읽는데만 2시간 이상" 분량 소구. **같은 값에 분량 열세** |
| **결정 3 — "9,900원 자리를 비워둔다"** | 9,900원은 아스텔로의 **진입가**. 비어 있지 않음 |
| **전제 B — 100~200원 초소액** | 시장 바닥이 880원. **100~200원은 존재하지 않는 가격대** |
| **헌장 — 신규 캐릭터 금지** | 8개 중 최고가(청월당 37,400원)가 캐릭터로 가격을 정당화. 근거였던 MAU 비교는 **"캐릭터가 단가를 올리나"에 답하지 않는다** |
| **"최대 경쟁자는 ChatGPT"** | 포스텔러가 이미 "Chat-GPT도 흉내낼 수 없는 만세력"을 카피로 사용. **업계 공통 인식** |
| **리텐션 = D7 게이트 통과 조건** | 덱 기준 리텐션은 **시장 최대 공백**. 비나리는 이미 물건(되물음·판결록·아침문안·스트릭)을 갖고 있는데 무기로 안 씀 |
| **환불 = 법적 방어 항목** | 덱은 같은 것을 **마케팅 자산**으로 봄 |

## 덱을 그대로 믿지 않는 이유 3개

1. **"8개사"인데 표에 7개.** 타이트사주가 맵에만 있고 표에서 빠짐.
2. **공급만 보고 수요를 안 봤다.** "2~3만원이 비어 있다"는 *아무도 안 판다*는 관찰이지 *누가 산다*는 근거가 아니다. **공백이 기회가 아니라 무덤일 수 있다.**
3. **성장 중인지 축소 중인지가 없다.** 8개를 늘어놨는데 매출·이용자 추이가 없다. 이전 조사에서 나온 점신 MAU −22.6%를 감안하면 이 시장이 커지는 중인지부터가 확인 대상.
